## 1. 产品概述

### 1.1 产品名称
**AI Dream / 我的梦境**

### 1.2 产品定位
一款基于 **FastAPI + React + MySQL + Qwen 大模型** 的梦境解析与轻玄学陪伴应用 MVP。通过 AI 帮助用户记录、理解梦境，并提供每日运势、心情追踪和轻量级会员服务，打造个人化的潜意识陪伴体验。

### 1.3 核心价值主张
- **记录**：快速保存梦境原文与醒来后的情绪状态
- **理解**：AI 生成梦境标题、标签、摘要与基础解梦结果
- **对话**：一轮 AI 追问引导用户补充信息，获取更贴近现实的补充解析
- **陪伴**：每日运势 + 心情记录 + 每日总结，形成持续的轻陪伴闭环
- **成长**：历史档案与连续记录天数，激励用户形成记录习惯

### 1.4 目标用户
- 18-35 岁对自我探索、情绪管理感兴趣的都市人群
- 有记录梦境习惯或希望培养该习惯的用户
- 对轻玄学、心理学、潜意识话题有好奇心的用户

## 2. 产品目标与验证重点（MVP 阶段）

| 目标 | 验证方式 |
|------|----------|
| 验证用户是否愿意持续记录梦境 | 连续记录天数、梦境提交频率 |
| 验证基础解梦结果是否有感知价值 | 反馈点击率、历史回看率 |
| 验证追问与补充解析是否能提高体验 | 追问完成率、反馈满意度 |

## 3. 功能模块

### 3.1 用户系统

#### 3.1.1 登录/注册
- **手机号登录**（MVP 阶段为 mock 登录，不校验真实短信验证码）
- **微信小程序登录**：通过 `wx.login` 获取 `code`，后端调用微信 `code2Session` 换取 `openid`，自动注册或绑定用户
- 首次登录自动注册，生成默认昵称
- 登录后下发 JWT Token（Bearer 格式），有效期 30 天

#### 3.1.2 个人中心
- 展示昵称、头像、会员状态、累计梦境数、连续记录天数
- 会员到期时间展示（若已开通）

### 3.2 梦境模块

#### 3.2.1 梦境输入
- 输入梦境原文（至少 10 字）
- 可选补充：醒来后情绪、梦里出现的人物、关键意象/画面
- 提交后全屏 loading + 动态进度条

#### 3.2.2 梦境解析结果
- **AI 自动生成**：标题、2-4 个标签、一句话摘要
- **基础解梦**：结论、符号解读、现实映射、提醒、宜/忌事项
- **追问问题**：AI 生成 1 个聚焦情绪/现实压力/关系的追问（25 字以内）
- **深度解析**：Pro 会员专享，包含核心信号、情绪模式、现实牵引、内在课题、建议、收束语

#### 3.2.3 追问与补充解析
- 每条梦境仅支持 **1 轮追问**
- 用户回答后，AI 基于原梦+回答生成补充解析（closerState / deeperReason / suggestion）

#### 3.2.4 历史记录
- 分页展示已保存的梦境列表
- 列表展示：日期、标题、原文、标签、摘要
- 支持查看详情、软删除
- 详情页展示：原文、基础解读、追问状态、补充解析、深度解读（会员）

### 3.3 心情模块

#### 3.3.1 心情记录
- 选择主情绪：开心 / 平静 / 焦虑 / 疲惫 / 难过 / 烦躁 / 迷茫
- 情绪强度：1-5 星
- 可选：一句话原因、原因标签
- 支持同一天多次记录

#### 3.3.2 心情历史
- 分页查看历史心情记录
- 支持按情绪类型筛选

### 3.4 每日总结模块

#### 3.4.1 自动生成
- 基于当天的心情记录和梦境记录，AI 生成每日总结
- 包含：整体状态、主要因素、注意点、提醒、饮食建议（方向/多吃/少吃/小贴士）
- 新增梦境/心情后自动刷新当天总结

#### 3.4.2 历史总结
- 分页查看过往每日总结

### 3.5 运势模块

#### 3.5.1 今日运势
- 按用户和日期缓存，每天只生成一次
- 内容包含：整体状态、提醒、爱情、事业、自我、宜/忌、幸运色、幸运时间
- 生成时会参考用户最近 5 条梦境的标签和情绪

### 3.6 会员与订单模块

#### 3.6.1 会员状态
- 当前用户会员等级：free / pro
- 展示会员方案：月度 Pro（¥28）、年度 Pro（¥168）
- 会员权益：无限次解梦、深度解析、完整历史记录、每周梦境总结

#### 3.6.2 订单系统（MVP Mock）
- 创建订单时返回 mock 支付参数
- 支持查询订单状态

### 3.7 反馈与埋点

#### 3.7.1 用户反馈
- 对梦境解析结果进行喜欢/不喜欢/建议等反馈
- 关联目标类型和目标 ID

#### 3.7.2 前端埋点
- 记录关键页面行为：首页浏览、梦境输入点击、梦境提交、结果查看、追问提交、运势查看、历史查看、会员页浏览、支付点击等

## 5. 用户旅程

### 5.1 首次使用
1. 打开应用 → 欢迎页引导
2. 手机号一键登录（自动注册）
3. 进入首页，看到今日状态卡片
4. 点击"记录梦境" → 输入梦境 → 提交
5. 查看解析结果，可选择回答追问
6. 返回首页，连续天数 +1

### 5.2 每日使用
1. 打开首页 → 查看今日总结/运势
2. 记录心情 / 记录梦境
3. 查看解析结果 / 回答追问
4. 浏览历史记录

## 6. 技术架构

### 6.1 后端
- **框架**：FastAPI
- **ORM**：SQLAlchemy 2.0（Declarative + Mapped）
- **数据库驱动**：PyMySQL
- **配置管理**：Pydantic Settings
- **大模型接入**：OpenAI Python SDK（DashScope 兼容模式）
- **认证**：JWT（自实现 auth_token 服务）

### 6.2 前端
- **框架**：React 19
- **构建工具**：Vite 4
- **路由**：Hash Router（自定义 `useHashRoute` hook）
- **样式**：原生 CSS（`styles.css`）

### 6.3 数据库
- **MySQL 8+**，InnoDB 引擎，utf8mb4 字符集

### 6.4 大模型
- **Qwen**（默认 `qwen-plus`），通过 DashScope OpenAI-compatible API 调用
- 未配置 API Key 时自动回退到本地 mock 生成逻辑

### 6.5 部署
- 后端通过 Uvicorn 运行
- 后端自动托管 `frontend/dist` 和 `frontend-english/dist` 静态资源
- Docker 支持（`Dockerfile` 已提供）

## 7. MVP 限制与后续规划

### 7.1 当前限制
- 登录为 mock 逻辑（无真实短信验证码）
- 支付为 mock 订单（无真实支付回调）
- 追问仅支持 1 轮
- 会员权限为基础版
- 运势生成基于最近梦境，未接入真实命理算法

### 7.2 后续可扩展方向
- 多轮追问与对话式解梦
- 梦境周报 / 月报自动生成
- 塔罗 / 抽签 / 起卦等轻玄学玩法
- 更完整的会员体系（季度卡、家庭卡等）
- 真实短信登录与微信授权手机号
- 真实支付接入（微信支付 / 支付宝）
- Prompt 配置化管理后台
- 梦境社区 / 匿名分享

## 8. 非功能需求

### 8.1 性能
- 接口响应时间：P95 < 500ms（不含大模型调用）
- 大模型调用超时：60s
- 前端首屏加载时间 < 3s

### 8.2 安全
- JWT Secret 生产环境必须替换
- 用户维度数据查询必须校验归属权
- 软删除用户数据，避免物理删除

### 8.3 可观测性
- 每次大模型调用写入 `prompt_logs` 表
- 前端关键行为写入 `event_logs` 表
- 全局异常统一捕获并返回标准错误结构
